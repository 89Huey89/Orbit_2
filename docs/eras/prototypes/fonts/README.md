# Prototype faces

Full faces as their publishers drew them, fetched from Google Fonts for the era prototypes
beside this folder, and never served by the game. Every one is under the SIL Open Font License
1.1 except Special Elite (Apache License 2.0). The game would embed a face only after cutting it
to the characters it sets (`npm run fonts`), exactly as the Fell types are cut today.
